# NEXUS

> **Everything connected.**

NEXUS is a futuristic React control center for devices, automation, gaming, media and system intelligence.

## ✨ Included

- Futuristic responsive dashboard
- Live device matrix UI
- Smart Home, Gaming, Media, Analytics and Security modules
- NEXUS AI command layer (local UI foundation)
- Integrated terminal (`⌘/Ctrl + Shift + Y` UI entry)
- Search and command actions
- Toast notifications
- Dark / light visual mode
- Glassmorphism, aurora effects and motion
- Mobile-first responsive layout

## 🧱 Stack

- React
- Vite
- Lucide React
- CSS design system

## 🚀 Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## 🌐 GitHub Pages

The project is structured as a Vite app and can be deployed with GitHub Actions or any static hosting provider.

## 🔌 Next integrations

The UI is intentionally ready for real integrations such as WebSockets, Supabase authentication, Philips Hue, Alexa, webOS, gaming APIs, cloud sync and voice control. No external device connection is claimed until its API/backend is configured.
